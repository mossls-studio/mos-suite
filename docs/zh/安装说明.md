# MOS 套件 v1.5.0 · 安装与使用说明

适用于 **EffectCraft**。套件共包含 **11 个效果**，在效果面板里分成五个分组：

| 分组 | 效果名称 | 效果 ID | 类型 | 版本 |
| --- | --- | --- | --- | --- |
| MOS 形变 | mos_抖动 | `mos.shake` | WASM | 1.2.0 |
| MOS 形变 | mos_收缩（变形·白点） | `mos.ae.warp` | WASM | 1.3.0 |
| MOS 液态 | mos_涟漪 | `mos.ripple` | WASM | 1.1.0 |
| MOS 液态 | mos_雨滴（支持自定义图层） | `mos.rain` | 外部助手 | 5.0.0 |
| MOS 液态 | mos_透镜（6 形状 + 自定义图层） | `mos.lens` | 外部助手 | 2.0.0 |
| MOS 视效 | mos_阴影 | `mos.shadow` | WASM | 0.6.2 |
| MOS 视效 | mos_灯光混合 | `mos.lightwrap` | 外部助手 | 1.5.0 |
| MOS 视效 | mos_打光（2D 偏移边缘光） | `mos.rimlight` | 外部助手 | 1.0.0 |
| MOS 效果 | mos_扫光（支持独立轮廓与发光） | `mos.lightsweep` | 外部助手 | 1.2.0 |
| MOS 效果 | mos_消散（粒子与像素分离） | `mos.dissolve` | 外部助手 | 1.0.0 |
| MOS 模糊 | mos_模糊 | `mos.blur` | WASM | 0.1.0 |

默认安装目录：`%APPDATA%\EffectCraft`（即 `C:\Users\<你的用户名>\AppData\Roaming\EffectCraft`）。

> **安全说明**：本项目为个人开源作品，未购买商业代码签名证书，部分杀毒软件或 Windows SmartScreen 可能会对 `.exe` 安装程序产生误报。如不信任安装程序，**可完全忽略 `.exe`，直接使用压缩包内的 `manual\` 文件夹进行手动安装**（见下方「方法二」）。

## 方法一：图形化分步安装程序（推荐）

双击运行 `MOS-Suite-Setup-1.5.0.exe`，按左侧步骤依次完成配置：

1. **欢迎**：查看套件概览与当前安装状态（可在左侧底部随时切换安装器中/英文界面）。
2. **语言设置**：
   - **效果名称**（跟随系统 / English）：决定效果面板里**分组名与效果名**的语言。
   - **参数语言**（跟随系统 / 中文 / English）：决定**效果控件里的参数名与下拉选项**语言。
3. **选择效果**：按需点击卡片勾选或取消要安装的效果（支持全选/全不选）。
4. **安装位置**：默认自动定位 `%APPDATA%\EffectCraft`，确认摘要后点击「开始安装」。
5. 完成后重启 EffectCraft 即可生效。

## 方法二：手动安装（无需运行 `.exe` 安装程序）

压缩包内的 `manual\` 目录已按标准结构整理好全部插件文件。

### 1. 退出 EffectCraft

先完全退出 EffectCraft；如果之前装过外部助手，请同时结束 `effectcraft-helper-mos-*.exe` 进程。

### 2. 复制文件到 `%APPDATA%\EffectCraft`

`manual\plug-ins\` 下为 5 个 WASM 插件准备了 4 种「名称 × 参数」语言组合：`zh-zh`、`zh-en`、`en-zh`、`en-en`（例如「中文名称 + 英文参数」选 `zh-en`）。按需复制对应文件：

| 目标位置（位于 `%APPDATA%\EffectCraft\`） | 来源（位于 `manual\`） |
| --- | --- |
| `Plug-ins\mos_shake.wasm` | `plug-ins\<组合>\mos_shake.wasm` |
| `Plug-ins\ae_warp.wasm` | `plug-ins\<组合>\ae_warp.wasm` |
| `Plug-ins\mos_ripple.wasm` | `plug-ins\<组合>\mos_ripple.wasm` |
| `Plug-ins\mos_shadow.wasm` | `plug-ins\<组合>\mos_shadow.wasm` |
| `Plug-ins\mos_blur.wasm` | `plug-ins\<组合>\mos_blur.wasm` |
| `helpers\effectcraft-helper-mos-rain.exe` | `helpers\effectcraft-helper-mos-rain.exe` |
| `helpers\effectcraft-helper-mos-lens.exe` | `helpers\effectcraft-helper-mos-lens.exe` |
| `helpers\effectcraft-helper-mos-lightmix.exe` | `helpers\effectcraft-helper-mos-lightmix.exe` |
| `helpers\effectcraft-helper-mos-rimlight.exe` | `helpers\effectcraft-helper-mos-rimlight.exe` |
| `helpers\effectcraft-helper-mos-lightsweep.exe` | `helpers\effectcraft-helper-mos-lightsweep.exe` |
| `helpers\effectcraft-helper-mos-dissolve.exe` | `helpers\effectcraft-helper-mos-dissolve.exe` |
| `Scripts\Startup\mos-load-helpers.jsx` | `Scripts\Startup\mos-load-helpers.jsx` |

> - 如从旧版升级，请删除 `Plug-ins\` 中遗留的旧版 `mos_rain.wasm`、`mos_lens.wasm` 或 `mos_shrink.wasm`，避免效果列表重复。
> - `Plug-ins`、`helpers`、`Scripts\Startup` 目录不存在时手动新建即可。**支持只装其中几个效果**，不需要的直接不复制。

### 3. 复制语言配置文件

将 `manual\mos-suite.zh.json`（全中文）或 `manual\mos-suite.en.json`（全英文）复制到 `%APPDATA%\EffectCraft\mos-suite.json`。
外部助手（`mos_雨滴`、`mos_透镜`、`mos_灯光混合`、`mos_打光`、`mos_扫光`、`mos_消散`）会读取其中的 `namesResolved` 与 `paramsResolved` 字段来决定显示语言。

### 4. 开启脚本权限（外部助手需要）

在 EffectCraft 中打开 **设置 ▸ Scripting & Expressions**，勾选 **Allow Scripts to Write Files and Access Network**，然后重启 EffectCraft。启动脚本会借此自动扫描并加载外部助手。

## 卸载

- **安装程序卸载**：重新打开 `MOS-Suite-Setup-1.5.0.exe`，在「欢迎」页左下角点击「卸载已安装」即可。
- **手动卸载**：退出 EffectCraft 后，删除上述复制的 `.wasm`、`helpers\effectcraft-helper-mos-*.exe`、`Scripts\Startup\mos-load-helpers.jsx`、`mos-suite.json` 及 `mos-suite\` 目录即可。

## 常见问题排错

- **外部助手（雨滴 / 透镜 / 灯光混合 / 打光 / 扫光 / 消散）未出现在效果栏**：执行 **效果 ▸ 扫描效果辅助程序…**，并确认已按第 4 步开启脚本读写权限。
- **覆盖文件时提示拒绝访问**：EffectCraft 或外部助手仍在后台运行，请完全退出后重试。
- **变形·白点（`mos.ae.warp`）语言不跟随切换**：该插件目前仅有中文清单，两种语言下均显示为 `mos_收缩`。
