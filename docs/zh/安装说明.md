# MOS 套件 · 手动安装说明

适用于 EffectCraft。套件含 4 个效果，在效果面板里分成两组：

| 分组 | 效果 | 效果 ID | 版本 |
| --- | --- | --- | --- |
| MOS 形变 | mos_抖动 | mos.shake | 1.2.0 |
| MOS 形变 | mos_收缩 | mos.shrink | 1.3.7 |
| MOS 视效 | mos_阴影 | mos.shadow | 0.6.2 |
| MOS 视效 | mos_灯光混合 | mos.lightwrap | 1.4.0 |

默认安装目录：`%APPDATA%\EffectCraft`（即 `C:\Users\<你的用户名>\AppData\Roaming\EffectCraft`）。

## 方法一：安装器（推荐）

双击 `MOS-Suite-Setup-1.0.0.exe`：

1. 选安装器语言（跟随系统 / 中文 / English）。
2. 选效果栏语言（跟随系统 / 中文 / English）——它决定效果面板里显示的分组名、效果名和参数名。
3. 在「组件」里勾掉不想装的效果。
4. 点「安装」，完成后重启 EffectCraft。

效果栏语言也可以在装完后随时重跑安装器修改，或者直接改 `mos-suite.json`（见下）。

## 方法二：手动安装

### 1. 退出 EffectCraft

先完全退出 EffectCraft；如果装了灯光混合，也结束 `effectcraft-helper-mos-lightmix.exe`。

### 2. 复制文件

把安装包里对应语言的文件放到下面这些位置（`<lang>` 是 `zh` 或 `en`）：

| 目标位置 | 来源 |
| --- | --- |
| `Plug-ins\mos_shadow.wasm` | `plug-ins\<lang>\mos_shadow.wasm` |
| `Plug-ins\mos_shake.wasm` | `plug-ins\<lang>\mos_shake.wasm` |
| `Plug-ins\mos_shrink.wasm` | `plug-ins\<lang>\mos_shrink.wasm` |
| `helpers\effectcraft-helper-mos-lightmix.exe` | `helper\effectcraft-helper-mos-lightmix.exe` |
| `Scripts\Startup\mos-load-helpers.jsx` | `scripts\mos-load-helpers.jsx` |
| `mos-suite\manual\zh\安装说明.md` | `manual\zh\安装说明.md` |
| `mos-suite\manual\en\Install-Guide.md` | `manual\en\Install-Guide.md` |

`Plug-ins`、`helpers`、`Scripts\Startup` 不存在就自己建。**只装部分效果也可以**：不放对应的 `.wasm` 就不会出现。

### 3. 写语言设置

在 `%APPDATA%\EffectCraft\mos-suite.json` 写（UTF-8，无 BOM）：

```json
{
  "schema": 1,
  "suiteVersion": "1.0.0",
  "effectsLanguage": "zh"
}
```

- `effectsLanguage` 填 `zh` 或 `en`。
- 四个效果的中文 / 英文名称和参数名由各插件自己的两份构建决定，**wasm 也要和语言对上**；灯光混合助手是同一份 exe，在启动时读这个文件决定显示中文还是英文。
- 不写这个文件时默认中文。

### 4. 打开脚本权限

EffectCraft ▸ 设置 ▸ Scripting & Expressions ▸ 勾选「Allow Scripts to Write Files and Access Network」，然后重启 EffectCraft。启动脚本要靠这个权限扫描效果助手。

### 5. 检查

打开效果面板，应该能看到 **MOS 形变** 和 **MOS 视效** 两个分组。拖动一个图层添加效果试试。

## 卸载

退出 EffectCraft，删除：

- `Plug-ins\mos_shadow.wasm`、`mos_shake.wasm`、`mos_shrink.wasm`
- `helpers\effectcraft-helper-mos-lightmix.exe`
- `Scripts\Startup\mos-load-helpers.jsx`
- `mos-suite\` 整个目录
- `mos-suite.json`

用安装器装的，重新打开安装器点「卸载」即可。

## 排错

**灯光混合不出现。** 效果 ▸ 扫描效果辅助程序…；确认 `helpers\effectcraft-helper-mos-lightmix.exe` 在，且 `Scripts\Startup\mos-load-helpers.jsx` 在、脚本权限已开。命令行可用 `effect.helpers.list` 看 `running: true`。

**灯光混合的背景图层位置不对。** 助手读不到背景图层的变换，这是已知限制：先把背景层预合成，再把它当背景图层用。

**覆盖 wasm 报拒绝访问。** EffectCraft 还开着，完全退出后重试。

**中文 / 英文没切换。** 检查 `mos-suite.json` 的 `effectsLanguage`，以及 `Plug-ins` 里的 wasm 是不是对应语言的那份；改完重启。

## 许可证

安装包内的 4 个效果按 MIT 许可证分发；灯光混合是对 Digital Anarchy Light Wrap Fantastic 的独立重实现，不包含对方的代码或素材。`mos_灯光混合` 这一名称仅用于说明效果用途。
