# MOS 套件 · 手动安装说明

适用于 EffectCraft。套件含 5 个效果，在效果面板里分成三组：

| 分组 | 效果 | 效果 ID | 版本 |
| --- | --- | --- | --- |
| MOS 形变 | mos_抖动 | mos.shake | 1.2.0 |
| MOS 形变 | mos_收缩 | mos.shrink | 1.3.7 |
| MOS 视效 | mos_阴影 | mos.shadow | 0.6.2 |
| MOS 视效 | mos_灯光混合 | mos.lightwrap | 1.5.0 |
| MOS 模糊 | mos_模糊 | mos.blur | 0.1.0 |

默认安装目录：`%APPDATA%\EffectCraft`（即 `C:\Users\<你的用户名>\AppData\Roaming\EffectCraft`）。

## 方法一：安装器（推荐）

双击 `MOS-Suite-Setup-1.2.0.exe`。安装器界面跟随系统语言，不需要选安装器语言；里面只有两组语言设置：

1. **效果名称**（跟随系统 / English）——决定效果面板里**分组名和效果名**用哪种语言。选「跟随系统」时跟着 Windows 显示语言走，系统不是中文就用英文。
2. **参数语言**（跟随系统 / 中文 / English）——决定**效果控件里的参数名和下拉选项**用哪种语言。选「跟随系统」时跟着系统走；套件没有系统语言对应的构建时（例如系统是日语）默认为英文。
3. 勾掉不想装的效果，确认安装位置，点「安装」，完成后重启 EffectCraft。

这两项设置装完可以随时重跑安装器修改，也可以直接改 `mos-suite.json`（见下）。

## 方法二：手动安装

### 1. 退出 EffectCraft

先完全退出 EffectCraft；如果装了灯光混合，也结束 `effectcraft-helper-mos-lightmix.exe`。

### 2. 复制文件

安装包里的四个 wasm 各准备了 4 种「名称 × 参数」组合，目录名就是 `<名称语言>-<参数语言>`：`zh-zh`、`zh-en`、`en-zh`、`en-en`。先定下你要的组合（例如「名称跟随系统=中文、参数=英文」就是 `zh-en`），再复制：

| 目标位置 | 来源 |
| --- | --- |
| `Plug-ins\mos_shadow.wasm` | `plug-ins\<组合>\mos_shadow.wasm` |
| `Plug-ins\mos_shake.wasm` | `plug-ins\<组合>\mos_shake.wasm` |
| `Plug-ins\mos_shrink.wasm` | `plug-ins\<组合>\mos_shrink.wasm` |
| `Plug-ins\mos_blur.wasm` | `plug-ins\<组合>\mos_blur.wasm` |
| `helpers\effectcraft-helper-mos-lightmix.exe` | `helper\effectcraft-helper-mos-lightmix.exe` |
| `Scripts\Startup\mos-load-helpers.jsx` | `scripts\mos-load-helpers.jsx` |
| `mos-suite\manual\zh\安装说明.md` | `manual\zh\安装说明.md` |
| `mos-suite\manual\en\Install-Guide.md` | `manual\en\Install-Guide.md` |

`Plug-ins`、`helpers`、`Scripts\Startup` 不存在就自己建。**只装部分效果也可以**：不放对应的 `.wasm` 就不会出现。

### 3. 写语言设置

在 `%APPDATA%\EffectCraft\mos-suite.json` 写（UTF-8，无 BOM）：

```json
{
  "schema": 2,
  "suiteVersion": "1.2.0",
  "namesLanguage": "system",
  "paramsLanguage": "system",
  "namesResolved": "zh",
  "paramsResolved": "zh"
}
```

- `namesLanguage` 填 `system` 或 `en`（`system` = 跟系统，非中文系统按英文）。
- `paramsLanguage` 填 `system`、`zh` 或 `en`（`system` 在套件没有对应语言时按英文）。
- `namesResolved` / `paramsResolved` 是实际生效的语言，**灯光混合助手读这两个值**；不写就退回 `namesLanguage` / `paramsLanguage`，再没有就用英文。
- 旧版只有 `effectsLanguage`（`zh` / `en`），同时决定名称和参数；新版仍认这个键，但优先用上面两对。
- 不写任何语言设置时默认全英文。

### 4. 打开脚本权限

EffectCraft ▸ 设置 ▸ Scripting & Expressions ▸ 勾选「Allow Scripts to Write Files and Access Network」，然后重启 EffectCraft。启动脚本要靠这个权限扫描效果助手。

### 5. 检查

打开效果面板，应该能看到对应的分组（**MOS 形变 / MOS 视效 / MOS 模糊**，或英文的 **MOS Deform / MOS VFX / MOS Blur**）。拖动一个图层添加效果试试。

## 卸载

退出 EffectCraft，删除：

- `Plug-ins\mos_shadow.wasm`、`mos_shake.wasm`、`mos_shrink.wasm`、`mos_blur.wasm`
- `helpers\effectcraft-helper-mos-lightmix.exe`
- `Scripts\Startup\mos-load-helpers.jsx`
- `mos-suite\` 整个目录
- `mos-suite.json`

用安装器装的，重新打开安装器点「卸载」即可。

## 排错

**灯光混合不出现。** 效果 ▸ 扫描效果辅助程序…；确认 `helpers\effectcraft-helper-mos-lightmix.exe` 在，且 `Scripts\Startup\mos-load-helpers.jsx` 在、脚本权限已开。命令行可用 `effect.helpers.list` 看 `running: true`。

**灯光混合的背景图层位置不对。** 助手读不到背景图层的变换，这是已知限制：先把背景层预合成，再把它当背景图层用。

**模糊装在调整图层上，边缘羽化看不出分级。** 调整图层的蒙版是在效果**之后**才生效的，wasm 里拿不到蒙版的几何信息，只剩 alpha=1 的整块图，所以只有「模糊大小」在均匀糊、「边缘羽化」不产生由内到外的分级。想要真正的边缘羽化，把效果挂在下面那个普通图层上（该图层的 alpha 就是蒙版覆盖率）。另外调整图层上不要开「保留原不透明度」，否则整个效果会消失。

**覆盖 wasm 报拒绝访问。** EffectCraft 还开着，完全退出后重试。

**名称和参数语言不一致 / 切换不生效。** 每个 wasm 只带一种「名称 + 参数」组合，改语言要用安装器重装（它会换对应 wasm），或者手动按第 2 步换成对应组合的 wasm；`mos-suite.json` 里的 `namesResolved` / `paramsResolved` 也要对应，改完重启。

**系统不是中文，但效果名还是中文。** 说明装的是 `zh-*` 组合，用安装器把「效果名称」改成 English 或「跟随系统」重装。
